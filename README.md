# #Utopia Real Estate Web Application

Overview
The Utopia Real Estate Web Application is a feature-rich platform for listing, searching, and exploring real estate properties. Designed using the MERN stack, the application provides users with an efficient and seamless experience for managing property listings and finding their ideal real estate matches.

Features
1. User Authentication
JWT Authentication: Secure user login and registration.
Google OAuth: Quick and efficient signup/login using Google accounts.
Session Management: Persistent login sessions with token refresh capabilities.
2. Property Listings
Users can create, edit, and delete property listings.
Upload up to 6 images per property, enhancing property visibility.
Listings include property details such as price, location, and description.
3. Search and Filter
Advanced search functionality to find properties based on location, price, and type.
Sorting and filtering options for customized results.
4. User Experience Enhancements
Fully responsive design powered by Tailwind CSS for optimal viewing on all devices.
Dark Mode: Toggle between light and dark themes for enhanced usability.
Seamless navigation with Redux Toolkit managing global state across components.
Tech Stack
Frontend: React.js, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB
State Management: Redux Toolkit
Authentication: JWT, Google OAuth
Key Metrics
Authentication Efficiency: Improved by 45% through the integration of JWT and Google OAuth.
State Management: Coordinated global state across 10+ components using Redux Toolkit.
